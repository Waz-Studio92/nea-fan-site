# nea-fan-wiki (雨見ねあ様 非公式ファンWiki)

個人勢VTuber「雨見ねあ」様の情報をまとめ、ファン同士が交流・共有できるコミュニティの土台として制作している非公式ファンサイトです。

## 🎯 制作意図
* **推し活の活性化:** 雨見ねあ様の魅力やガイドライン、歌唱楽曲を網羅し、ファンコミュニティに貢献すること。
* **Vanilla JavaScriptの探求:** ライブラリ（React等）に頼る前段階として、ピュアなJavaScriptを用いたコンポーネント化やデータ管理の実戦経験を積むこと。

## 📄 各ページ構成
* **index.html:** 雨見ねあ様の基本情報や最新の活動内容を掲載。
* **guide-line.html:** ファンが安心して推し活を行うための、雨見ねあ様の二次創作等のガイドラインを記載予定。
* **sing_list.html:** これまでに歌唱された楽曲のデータを `<table>` 要素を用いて美しくリスト化して記載予定。

## 🛠️ 技術スタック & 設計方針
* **言語:** HTML5 / CSS3 / JavaScript (ES6+ / Vanilla JS)
* **開発環境:** Vite (HMRによる爆速なローカル開発の実現)
* **ホスティング:** GitHub ＋ VercelによるCI/CD環境

### 🔥 こだわりの設計（Fetch ＋ JSONによるコンポーネント化）
HTMLの保守性を高めるためのコンポーネント化の試みとして、ヘッダーやフッターなどの共通パーツ、および各コンテンツの主要なデータを `assets/data/` 内のJSONファイルに分離・保管しています。
非同期処理（`async/await`）と `Fetch API` を駆使して動的にHTMLへデータを流し込む仕様を採用しており、将来的な拡張性を担保しています。

## タイトル：feat: 親フォルダを削除しVite環境をルート直下に適正化

詳細（Extended description）：
- Vercelの404エラー（NOT_FOUND）を解消するため、不要な親フォルダを削除
- package.jsonがある階層（nea-fan-wiki）をリポジトリのルートに設定
- これにより、手元の `npm run dev` とVercelの本番ビルドの階層を一致させた
